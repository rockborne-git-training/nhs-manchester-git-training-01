Welcome to your first exercise on Git training!

In this exercise, you will create your first commits, but with a challenge!

We're going to be adding some text into this webpage and making a couple of changes.

You will insert text noting down what steps we have taken so far to get here e.g. creating a GitHub repository.

  1. Installed Git
  2. Installed a code editor
  3. Created a GitHub account
  4. Created a new repository on GitHub
  5. Made a new repository in Git to save all our files into
  6. Initialised the Git repository
  7. Linked our GitHub repository to our Git repository
  8. Opened a new file in our code editor
  9. Created our HTML, JavaScript and CSS files
